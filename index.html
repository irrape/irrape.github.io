Project 3: Tech Away

Full-stack web application built with PHP and Apache for server-side logic and SQL for database operations.

The front-end was developed using HTML, CSS and JavaScript for form validation and interface animations.

Access control was implemented based on user roles, allowing the platform to display different pages and functionalities depending on whether the user is an admin or a regular user, ensuring both security and a user-specific interface.

This is my first full-stack project, a collaborative web platform showcasing top techno venues worldwide.

Users can register, submit news, and book appointments via dynamic forms. Content and access adjust by user role with admins managing posts and appointments while regular users have limited features.
