Proyecto 1: Shiverflix

Desarrollado con HTML y CSS responsivo para garantizar la accesibilidad y una experiencia de usuario fluida en todos los dispositivos.

También implementé una integración sencilla de Google Maps para mostrar una ubicación comercial ficticia y utilicé código personalizado para animar el logotipo, con el fin de experimentar con divs y añadir una identidad dinámica a la plataforma.

Este fue el primer proyecto personal que construí.

Mi objetivo era tener un espacio donde pudiera llevar un registro de las películas, series y documentales que he visto y recomendarlos junto con las plataformas de streaming donde están disponibles, todo ello de forma sencilla.

Proyecto 2: Libroasis

Aplicación front-end desarrollada con HTML, CSS responsivo y JavaScript.

Incluye actualizaciones de contenido en tiempo real mediante AJAX y JSON, así como un mapa interactivo con Leaflet que muestra la ubicación ficticia de la librería.

También implementé un logotipo animado personalizado y transiciones fluidas para dotar a la plataforma de una identidad dinámica y distintiva.

Una librería ficticia donde los usuarios pueden explorar y encargar nuevos libros de una forma original.

El proyecto incluye formularios y animaciones sutiles para crear una experiencia de usuario más dinámica.

Proyecto 3: Tech Away

Aplicación web full-stack desarrollada con PHP y Apache para la lógica del servidor y SQL para las operaciones de base de datos.

El front-end se desarrolló con HTML, CSS y JavaScript para la validación de formularios y animaciones de interfaz.

El control de acceso se implementó en función de los roles de usuario, lo que permite que la plataforma muestre diferentes páginas y funcionalidades según si el usuario es administrador o usuario normal, garantizando así la seguridad y una interfaz personalizada.

Este es mi primer proyecto full-stack: una plataforma web colaborativa que muestra los mejores locales de música techno del mund

Los usuarios pueden registrarse, publicar noticias y reservar citas mediante formularios dinámicos. El contenido y el acceso se adaptan al rol del usuario: los administradores gestionan las publicaciones y las citas, mientras que los usuarios normales tienen funciones limitadas.

Project 4: ARKitecture

La interfaz de usuario de este proyecto está desarrollada con HTML5 y CSS3, y mejorada con Bootstrap para un diseño adaptable y sin interrupciones en todos los dispositivos.

He añadido JavaScript para proporcionar interactividad y permitir la gestión dinámica del contenido, incluyendo funciones como animaciones fluidas.

ARKitecture es un proyecto que exhibe obras arquitectónicas icónicas e innovadoras de todo el mundo.

Destaca diversos estilos, técnicas e influencias culturales, permitiendo a los usuarios explorar diseños inspiradores de las principales ciudades del planeta.

Project 5: Retro Games Prototype

Retro Games es un prototipo de aplicación móvil desarrollado en Figma con maquetas de alta fidelidad y componentes interactivos.

Se centra en flujos de aplicación realistas, capacidad de respuesta de la interfaz de usuario y diseño de interacción para juegos móviles.

Retro Games es un prototipo en Figma de una aplicación móvil con juegos arcade clásicos como Pac-Man y Street Fighter.

Permite a los usuarios jugar a juegos retro nostálgicos en sus teléfonos y competir con otros jugadores en tiempo real.
